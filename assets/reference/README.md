# Original Conan (Datasoft, 1984) — reference screenshots

Source: MobyGames — https://www.mobygames.com/game/9293/conan/screenshots/
Downloaded for art/palette/level-layout reference for the remake. Not for redistribution.

53 full-size PNGs by platform:

| Platform    | Count | Native res | Notes                                         |
|-------------|-------|------------|-----------------------------------------------|
| apple2      | 11    | 560×384    | Cast of Characters + Objects legend + L1–L4   |
| atari-8-bit | 7     | ~336×240   | Title, game start, a couple layouts, game over|
| c64         | 18    | 320×200    | Most complete death/HUD set, L1–L4            |
| sharp-x1    | 17    | 640×400    | Highest res; full level set L1–L8 + ending     |

For level-layout reference, **sharp-x1** (cleanest, highest res) and **c64**
(complete) are the most useful. `objects.png` / `cast-of-characters.png` document
the original sprites and pickups.
